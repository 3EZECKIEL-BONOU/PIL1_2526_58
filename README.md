# 📘 GUIDE D’UTILISATION

## Plateforme : IFRIMentorLink

---

# 1. Présentation générale

La plateforme **IFRIMentorLink** est une application web conçue dans le cadre d’un projet académique de Licence 1 à l’IFRI. Elle a pour objectif de faciliter la mise en relation entre étudiants (mentorés) et étudiants expérimentés (mentors) afin d’améliorer l’accompagnement académique.

Elle permet principalement :

* l’inscription des utilisateurs ;
* la connexion sécurisée ;
* la gestion des profils mentors et mentorés ;
* la recherche et recommandation de mentors ;
* la gestion des demandes de mentorat.

---

# 2. Objectifs du projet

Le projet IFRIMentorLink vise à :

* faciliter l’orientation des nouveaux étudiants ;
* encourager l’entraide entre étudiants ;
* améliorer la communication académique ;
* proposer un système intelligent de recommandation de mentors ;
* développer des compétences en développement web (Django, HTML, CSS, JavaScript).

---

# 3. Public cible

La plateforme s’adresse aux :

* Étudiants de l’IFRI (toutes filières confondues) ;
* Mentors souhaitant accompagner d’autres étudiants ;
* Responsables académiques.

# 5. Accès à la plateforme

## 5.1 Page d’accueil

La page d’accueil permet à l’utilisateur de :

* découvrir la plateforme ;
* accéder à la connexion ;
* accéder à l’inscription.

---

## 5.2 Inscription

L’utilisateur doit créer un compte en renseignant :

* nom et prénom ;
* email ;
* mot de passe ;
* filière ;
* rôle (mentor ou mentoré).

Une fois validé, le compte est enregistré dans la base de données.

---

## 5.3 Connexion

Pour se connecter :

1. entrer l’email ;
2. entrer le mot de passe ;
3. cliquer sur **Se connecter**.

L’utilisateur est redirigé vers son tableau de bord.

---

# 6. Fonctionnalités principales

## 6.1 Tableau de bord

Permet de voir :

* les activités récentes ;
* les recommandations ;
* les demandes en cours.

---

## 6.2 Explorer les mentors

L’utilisateur peut consulter :

* les profils des mentors ;
* leurs domaines ;
* leurs disponibilités.

---

## 6.3 Demande de mentorat

L’utilisateur peut envoyer une demande à un mentor.
Le mentor peut ensuite :

* accepter ;
* refuser.

---

## 6.4 Recommandation automatique

Le système propose des mentors selon :

* la filière ;
* le niveau ;
* les centres d’intérêt.

---

## 6.5 Mes mentors

Affiche les mentors acceptés et les échanges en cours.

---

# 7. Fonctionnement technique

La plateforme est développée avec :

* **Frontend :** HTML, CSS, JavaScript
* **Backend :** Django (Python)
* **Base de données :** PostgreSQL / MySQL

Le système utilise un algorithme de matching pour améliorer la qualité des recommandations.

---

# 8. Conclusion

La plateforme **IFRIMentorLink** représente une solution numérique innovante visant à améliorer l’accompagnement académique des étudiants de l’IFRI. Elle favorise la collaboration, le partage de connaissances et l’entraide entre étudiants.
