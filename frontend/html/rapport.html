Résumé

IFRIMentorLink est une plateforme web de mentorat académique permettant de mettre en relation des mentors et des mentorés afin de faciliter l’accompagnement des étudiants.

1. Introduction

Contexte

Les étudiants rencontrent souvent des difficultés d’adaptation à l’université et ont besoin d’un accompagnement personnalisé.

Problématique

Comment faciliter l’accompagnement des étudiants de l’IFRI à travers une plateforme numérique ?

Objectifs

  • Mettre en relation mentors et mentorés
  • Faciliter l’orientation académique
  • Développer une plateforme fonctionnelle

2. Présentation du projet

Description

IFRIMentorLink est une application web permettant de connecter les étudiants selon leurs besoins et leurs profils.

Fonctionnalités

  • Inscription et connexion
  • Gestion des profils utilisateurs
  • Exploration des mentors
  • Demandes de mentorat
  • Recommandation automatique

3. Réalisation du projet

Technologies utilisées

  • HTML / CSS / JavaScript
  • Django (Python)
  • Base de données SQL
